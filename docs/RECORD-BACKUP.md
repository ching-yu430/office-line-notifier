# 網頁紀錄備份與自動下載：2026.11.19.2

管理員可在「系統管理 → 資料維護 → 紀錄備份」直接產生並下載 ZIP。這是完整行政紀錄的匯出，不受畫面最近 500 筆或教師對話最近 200 則的載入限制。沒有新增 R2、Supabase、公開下載網址或雲端備份儲存；ZIP 在管理員瀏覽器打包，存到辦公室電腦。

## 手動下載

1. 管理員登入，進入系統管理的「資料維護」分類，找到「紀錄備份」。
2. 按「下載 ZIP 備份」，等待筆數進度完成。
3. 在 Chrome 的下載紀錄確認檔案已保存；可按 `Ctrl + J` 查看。頁面顯示「上次產生」，不把瀏覽器啟動下載直接當成檔案一定保存成功。
4. 將檔案放到學校核准的位置。備份含行政個資，不要上傳公開 GitHub、公開網站或聊天群組。

檔名採台灣時間，例如 `office-records-20261118-153000-xxxxxxxx.zip`；最後一段隨機識別避免覆寫同名檔案。

## ZIP 內容

| 檔案 | 用途 |
| --- | --- |
| `records.json` | 保留原始文字及各類完整紀錄、識別碼、筆數與版本 |
| `csv/teachers.csv` | 教師姓名、單位、備註與綁定狀態，沒有 LINE User ID |
| `csv/staff.csv` | 行政人員名稱、角色及啟用狀態，沒有登入帳號或密碼雜湊 |
| `csv/notifications.csv`、`csv/messages.csv` | 通知內容、發送及處理狀態、聊天文字與時間 |
| 其他 `csv` | 對話處理狀態、通知範本、交接與修改歷程、內部備註、操作紀錄 |
| `manifest.json` | 格式版本、程式版本、筆數及各檔案 SHA-256 檢查碼 |
| `備份說明.txt` | 保存與使用說明 |

CSV 使用 UTF-8 BOM，方便 Windows Excel 開啟。對可能成為試算表公式的文字加入安全前綴，避免 `= + - @` 或控制字元造成公式注入；**原始文字以 JSON 為準**。

此備份刻意不包含密碼雜湊、Session、CSRF、LINE Token／Secret、LINE User ID、綁定碼及防重複發送帳本。適合長期保管、查閱及比對行政紀錄，**不能單獨重建完整登入、LINE 綁定與系統資料庫**。沒有提供將 ZIP 直接匯入正式資料庫的功能。完整系統還原仍需保留 D1 SQL 備份與後端 Secrets，見下方說明。

## 自動備份設定

自動寫入資料夾需要 Windows Chrome／Edge 支援的資料夾選擇及瀏覽器鎖定 API；未支援時仍可手動下載 ZIP。

1. 進入「資料維護」分類的紀錄備份，按「選擇自動備份資料夾」，選擇校內核准的位置並允許寫入。
2. 將間隔設成「每 1 天」、「每 7 天」或「每 30 天」。預設為關閉。
3. 尚未產生過備份時會先做一次，之後依上次產生時間判斷是否到期。
4. 網頁開啟且管理員仍登入時，任一主頁均可執行排程，不必停留在系統管理。為避免多視窗重複寫入，同一帳號的自動備份使用瀏覽器鎖並再次確認上次時間。

重要限制：

- **網頁關閉、電腦休眠或登出後不會繼續執行。** 背景分頁暫停，到前景後補做一次，並非保證在某一秒準時執行。
- 設定與上次產生時間只存於這台電腦、這個瀏覽器、這個帳號，不是所有行政人員共用的全校排程。
- 資料夾授權只留在本次登入記憶體，重新整理、重新開啟或重新登入後，需再次選擇資料夾。頁面會顯示「請先選擇資料夾」，不會假裝排程已持續運作。
- 權限被撤銷時停止自動寫入並顯示需要重新授權；不會自行跳出權限視窗。自動失敗最多五分鐘後再嘗試，避免不斷重複請求。
- ZIP 使用新檔名，不覆寫或自動刪除既有備份。請自行按校內規範管理舊備份容量。
- 不需要設定 Cloudflare API Token 或新增 Secrets。若未來需要關閉網頁後仍定時備份，應另用經授權的 Windows 工作排程器或其他備份環境；本版沒有建立背景工作。

## 完整性與容量

後端提供管理員專用的完整分頁讀取。備份識別含擁有者、版本、筆數及十分鐘期限，以後端 `AUTH_PEPPER` 衍生 HMAC 保護；前端無法修改資料表或版本。每頁固定最多 100 筆，SQL 欄位與資料表皆採白名單。

新增 `backup_version` 只追蹤行政紀錄，不受查看訊息與輸入提示干擾。若紀錄內容在分頁讀取或打包期間更新，後端拒絕完成，前端最多重做一次；仍持續更新時提示稍候重試，**不提供混合版本或部分內容的 ZIP**。每類實際筆數均須與起始筆數相同才可下載。

瀏覽器原始資料上限 50 MiB、打包檔案上限 64 MiB，超過時顯示改用 D1 SQL 匯出的提示，不會默默截斷。大量歷史資料的完整備份仍應以維護工具處理。ZIP 在電腦端壓縮，不把副本存回 D1，因此不會用資料庫容量儲存另一份相同正文。

產生完成會留下「產生紀錄備份」操作紀錄、筆數、檔案大小與 SHA-256，不包含備份正文。這表示檔案已產生，不代表瀏覽器必定保存成功；自動備份必須等資料夾寫入完成才更新上次時間。取消、登出或切換身分會阻止尚未完成的備份下載及自動寫入。

## 完整 D1 備份與還原

以下會讀取遠端資料；只有在你確認需要正式備份，且本機設定指向正確專案時執行。SQL 含密碼雜湊及 LINE 身分，比網頁紀錄 ZIP 更敏感：

```powershell
fnm env --shell powershell | Out-String | Invoke-Expression
fnm use 24
New-Item -ItemType Directory -Force .local | Out-Null
$officeBackupPath = Join-Path ".local" ("full-d1-" + (Get-Date -Format "yyyyMMdd-HHmmss") + ".sql")
npx.cmd wrangler d1 export office-line-notifier --remote --output $officeBackupPath
```

SQL 備份不包含 Cloudflare Secrets，金鑰需另外安全保管。還原應先在隔離資料庫演練，勿直接覆寫正式庫；步驟見 [維運文件](OPERATIONS.md)。本次沒有執行正式備份、還原、部署或發送真實 LINE。

## 本機預覽及更新

HTML 預覽的同一個按鈕可產生虛構資料 ZIP，不連接正式 API。自動資料夾功能取決於使用者瀏覽器及權限，Windows 原生資料夾選擇仍需在你的電腦驗收。

正式更新前先備份，依序套用尚未執行的 0003、0004，以及新增 **0005_record_exports.sql**。0005 只新增備份版本與觸發器，不會備份或刪除現有紀錄，不需新增帳密或 Secrets。更新檔案與 Windows 指令見 [整合更新說明](CONVERSATION-UPDATE.md)。
