# 程式安全與穩定性檢查：2026.11.18.5

範圍包含 React 介面、資料快取、登入與 Session、Workers API 權限、SQL 參數、LINE Webhook／發送防重複、紀錄清理、備份、套件依賴及本機開發設定。使用本機 workerd／D1、瀏覽器測試與靜態程式檢視，沒有對正式網站做滲透測試、修改正式資料或發送真實 LINE。

## 已修正的問題

| 問題 | 修改與驗證 |
| --- | --- |
| 成功登入也持續累計帳號限制，正常重登可能被鎖住 | 成功驗證後清除帳號失敗桶；五次錯誤仍會限制。IP 的請求限制保留。新增重複成功登入與錯誤限制測試。 |
| 不同帳號的連字號被正規化，可能共用限制桶 | 登入桶改用原始小寫帳號的 HMAC；綁定碼仍使用原有正規化。密碼修復工具同時清除新舊桶，密碼雜湊格式及 pepper 不變。 |
| 登出重登後舊 401 可能清除新登入的狀態 | API 請求記住工作階段版本；舊版本回應不清除新 Session／CSRF。新增延遲回應測試。 |
| 同一毫秒的聊天用隨機 ID 排序，可能順序顛倒 | 後端回傳資料庫序號，時間相同時依實際序號排序；快照、個別對話與前端一致。新增反向字母 ID 測試。 |
| 清理預覽後正文撤回，對話狀態不一定改變 | 預覽保存教師對話版本，執行時一併檢查；即使狀態仍是已完成，正文改變也整批拒絕。 |
| 啟用狀態字串可能被當作真值；不存在對話產生一般錯誤 | 教師與帳號明確驗證布林值；不存在教師回 404。後端權限與 SQL 約束維持。 |
| 快照不需回傳所有通知內部欄位 | 快照與聊天領件改用欄位白名單，排除 retry key、綁定版本及 operation token。 |
| 預覽儲存格式損壞可能令展示版無法啟動 | 讀取虛構快取時檢查必要陣列；格式不符改用展示資料，不影響正式 D1。 |
| 紀錄備份可能只匯出畫面載入部分、混用不同版本或執行 CSV 公式 | 全資料庫分頁、版本與筆數檢查、HMAC 識別、角色／來源／CSRF 驗證、雜湊清單及 CSV 公式防護。原文保留在 JSON。 |
| 自動備份跨視窗、授權撤銷、登出後可能繼續寫入 | 瀏覽器鎖、資料夾權限檢查、登入世代取消、隱藏分頁暫停及失敗退避；不長期保存資料夾 handle。 |

系統管理折疊使用原生按鈕、`aria-expanded`、`aria-controls` 與真正隱藏的內容區域；收合狀態只在本次登入的記憶體保存。權限變成一般行政時離開系統管理，後端仍獨立驗證每個管理操作。

## 依賴公告與處理狀態

已將 Vite 更新到 `8.3.8`，以套件 overrides 將開發工具依賴 `undici` 固定為 `7.30.1`、`sharp` 固定為 `0.35.5`，重新安裝及執行整合／瀏覽器驗證。新增的 ZIP 套件為 MIT 授權 `fflate 0.8.3`，只使用同步 ZIP 壓縮，不啟用動態 worker、第三方服務或付費功能。

尚未完全消除的公告：`picomatch` 的 [GHSA-fc5q-39xc-vjpf](https://github.com/advisories/GHSA-fc5q-39xc-vjpf) 指出重複 extglob 的 ReDoS。本次 npm registry 查到的 latest 仍為 `4.0.7`，仍落在受影響範圍，沒有已發布的安全升級可套用。完整 `npm audit` 會因同一根源列出 **picomatch、fdir、tinyglobby、vite、vitest 五個 high 節點**；沒有把它標成已修復，也沒有用強制降級主版本來掩蓋公告。

這些套件用在開發／測試，不會部署到 Pages 靜態成品或 Workers 執行程式。開發及預覽伺服器預設只綁定 `127.0.0.1`，不向區域網路開放；不要將不可信的 glob 設定交給開發工具，也不要把開發伺服器當作正式服務。後續需持續追蹤上游修補版，更新後再驗證。正式執行依賴的檢查以 `npm audit --omit=dev` 結果為準，詳見測試報告。

## 已檢查並保留的保護

- LINE Token／Channel Secret、AUTH／BINDING pepper 只由後端讀取，不寫入前端、ZIP 或終端機紀錄。
- Session 使用安全隨機值、後端雜湊、HttpOnly／SameSite Cookie；公開服務不能關閉 Secure。管理員及一般行政權限在 Workers 驗證。
- 寫入 API 驗證來源、Content-Type、本文大小與 CSRF；SQL 值使用參數，備份資料表及欄位只從固定白名單選擇。
- Webhook 以原始本文驗證 HMAC，缺少金鑰、損壞簽章與異常事件不能通過；事件去重、撤回與綁定唯一性由資料庫保護。
- 通知發送保留請求指紋、原子領取、結果未明不重送；清理後的原請求不能再次建立通知。
- 綁定碼採安全隨機、HMAC 雜湊、一次性、期限與限流；沒有為備份匯出綁定碼或 LINE User ID。
- React 以文字呈現外部內容，沒有新增 `innerHTML`／eval；正式頁面維持 CSP、nosniff 與 frame 防護。
- 清理與多筆領件維持 D1 原子批次、版本檢查及稽核；備份不繞過清理保護。

## 檢查限制

這是程式與依賴檢查，不能證明永遠沒有漏洞。真實 Cloudflare 帳號權限、Secrets 設定、正式免費方案 CPU／流量、多日排程、Windows 原生資料夾選擇與完整災難還原，仍需在使用者環境驗收。所有 LINE HTTP 為 Mock；正式環境沒有在本次公開部署或改動。
